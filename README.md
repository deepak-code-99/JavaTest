#java calculator project 
A SIMPLE COMMAND LINE CALCULATOR APPLICATION BUILT IN JAVA IN THE SCANNER CLASS .
# HOW TO USE IT :
i) enter the  first digit that you have to calculate and click enter  and after that enter your second digit and click enter 
ii) after that put this  =  sign and click enter

features

* error handling built in check to prevent error handling
